# Projeto: Geo-Explorer



## 📚 Descrição:
>***O repositório é um Lab. (laboratório) com intenção de aplicar conceitos do IBM Bob como AI Copilot (copiloto de IA) para criar, testar e documentar uma solução completa para uma problemática, nesse caso em específico, construir uma experiência de exploração de trilhas de aprendizagem. O usuário consultará trilhas e receberá um desafio de código para gerar um certificado sintético (fictício).***

## ✅ Tópicos de Construção:
- *Trilha:* Apresenta um plano de estudos de acordo com a tecnologia escolhida;
- *Desafio:* Gera um desafio de código conforme a tecnologia e o nível informado;
- *Certificado:* Cria um certificado fictício para uma trilha concluída.
